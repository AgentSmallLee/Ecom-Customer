1.说一下你最近做的一个项目，以及你在其中担任的角色

答：我最近做的项目是「红松心选电商 AI 智能客服系统」，我担任的是这个项目的独立主导者，从架构设计、前后端开发到评估迭代全程负责，是从 0 到 1 的完整落地。

【背景】电商平台人工客服咨询量大、响应慢、夜间无人值守，急需要一个 AI 客服承接高频咨询场景。

【项目是什么】基于 LangGraph + RAG + function calling 构建的多链路智能客服，覆盖订单/物流查询、商品与售后知识问答等高频场景，支持流式回复和节点执行轨迹可视化，全栈 TypeScript 交付（后端 NestJS + 前端 Vue 3）。

【我的角色与职责】
1. 架构设计：独立设计 LLM 应用核心五层（基础层/编排层/记忆层/工具层/知识层）+ 工程落地三层（认证层/可观测性/前端层），搭建结构化、可扩展的生产级 Agent 系统
2. 全栈开发：后端用 NestJS + LangChain/LangGraph 实现工作流编排、RAG 检索、工具调用；前端用 Vue 3 手写 SSE 流式解析，实现逐 token 打字机与节点轨迹可视化

【核心实现（可展开说）】
- 编排层：LangGraph StateGraph 多链路工作流，LLM 意图路由分叉成「订单查询 / 知识问答 / 通用闲聊」三条链路，updates 模式推节点状态、custom 模式推 token
- 知识层：混合检索 RAG——向量检索（pgvector）+ BM25 关键词检索双路召回、RRF 融合，返回来源引用
- 记忆层：三层记忆——短期会话记忆（Checkpointer）、长期用户偏好记忆（function calling 提取 + 跨会话召回）、摘要压缩（LLM 压缩 + RemoveMessage 裁剪）
- 工具层：LangChain createAgent 驱动 function calling，工具参数 zod schema 约束，订单查询工具内置归属校验防越权
- 可靠性：主备双模型 + 30s 超时 + 静态兜底三级降级，Prisma 全链路审计日志 + LangSmith 链路追踪
- 评估：LLM-as-Judge 离线评估，召回率/准确率/生成质量三维度打分，一键脚本自动回归对比

【成果与角色总结】一个人承担了从需求分析、架构设计、编码实现到离线评估、持续迭代的完整闭环；系统上线后有效承接了高频咨询，也让 RAG 的优化从"凭感觉"变成了"看指标"。
