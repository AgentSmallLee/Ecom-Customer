# 前端技术栈总结

> 项目：ecom-ai-customer（红松心选 AI 客服）
> 目录：`note/`
> 更新时间：2026-09

## 一、核心框架

| 技术 | 版本 | 说明 |
|------|------|------|
| **Vue 3** | ^3.4.0 | 核心框架，全面使用 **Composition API**（`<script setup>` 语法糖） |
| **Vue Router 4** | ^4.3.0 | SPA 路由，`createWebHistory` 模式，4 个页面路由 |
| **TypeScript** | ^5.9.3 | 全量 TypeScript，严格模式（`strict: true`），所有 `.ts` 和 `.vue` 均用 TS |

## 二、构建工具

| 技术 | 版本 | 说明 |
|------|------|------|
| **Vite** | ^5.0.0 | 构建工具 & 开发服务器，端口 5173 |
| **@vitejs/plugin-vue** | ^5.0.0 | Vite 的 Vue SFC 编译插件 |
| **vue-tsc** | ^3.3.11 | Vue SFC 类型检查，构建前先跑 `vue-tsc --noEmit` |

### 构建脚本
```json
{
  "dev":       "vite",
  "build":     "vue-tsc --noEmit && vite build",
  "preview":   "vite preview",
  "typecheck": "vue-tsc --noEmit"
}
```

### tsconfig 关键配置
- `target: ES2020`、`module: ESNext`、`moduleResolution: bundler`
- `strict: true`（严格类型检查）
- `jsx: preserve`、`noEmit: true`
- `types: ["vite/client"]`

## 三、状态管理

**无 Pinia / Vuex**，采用 Vue Composition API 原生方案：

- 每个功能一个 **composable** 封装状态与逻辑
- 使用 `ref()` 管理响应式状态
- 视图组件纯展示，逻辑全部抽到 composable 中

### 现有 composables
| 文件 | 职责 |
|------|------|
| `src/composables/useChat.ts` | 基础对话：消息历史、流式输出、错误处理 |
| `src/composables/useAgent.ts` | Agent 模式：工具调用步骤渲染 |
| `src/composables/useRag.ts` | 知识库问答：参考来源展示 |
| `src/composables/useGraph.ts` | Graph 多 Agent：工作流节点轨迹、意图识别、记忆管理 |

## 四、网络 & 流式通信

- **原生 `fetch` API** — 不使用 axios 等 HTTP 库
- **手动 SSE 解析** — 用 `response.body.getReader()` + `TextDecoder` 逐块读取流，解析 `data: ` 前缀的 JSON 事件
  - 为什么不用 `EventSource`：`EventSource` 只支持 GET，项目需要 POST 发送消息体
- **流式实时渲染** — 每个 token 到达后通过 `nextTick()` 触发视图更新，实现打字机效果
- API 基址硬编码为 `http://localhost:3000/api`

### 后端接口
| 接口 | 方法 | 说明 |
|------|------|------|
| `/chat/stream` | POST | 基础对话流式返回 |
| `/agent/stream` | POST | Agent 工具调用流式返回 |
| `/rag/query` | POST | 知识库问答 |
| `/graph/stream` | POST | Graph 工作流流式返回（含 node / steps / answer 事件） |

## 五、样式方案

- **纯手写 Scoped CSS** — 每个 `.vue` 单文件组件内 `<style scoped>`
- **无 CSS 框架**（无 Tailwind / Element Plus / Ant Design Vue 等）
- **无 CSS 预处理器**（无 Sass / Less）
- 全局重置 & 导航样式在 `App.vue` 的非 scoped `<style>` 中
- 配色：自定义 slate/blue 色系（`#1e293b`、`#2563eb`、`#f8fafc` 等）
- 动画：CSS keyframes（光标闪烁、加载点动画、思考点跳动等）

## 六、类型定义

| 文件 | 说明 |
|------|------|
| `src/types.ts` | 前后端共享数据契约：`ChatMessage`、`ToolStep`、`SourceInfo` |
| `src/vite-env.d.ts` | Vite 客户端类型引用 + `*.vue` 模块声明 |
| 各 composable 内 | 各功能的消息类型 & SSE 事件类型（如 `GraphMessage`、`GraphStreamEvent`） |
| `src/router/index.ts` | 通过 `declare module 'vue-router'` 扩展 `RouteMeta` 类型 |

## 七、浏览器 API 使用

| API | 用途 |
|-----|------|
| `localStorage` | 持久化用户 ID（长期记忆 key，`ecom_user_id`） |
| `crypto.randomUUID()` | 生成 `threadId`（会话/短期记忆 key）和初始 `userId` |
| `ReadableStream` / `TextDecoder` | 解析 SSE 流式响应 |
| `nextTick` | 流式渲染后等待 DOM 更新再滚动 |

## 八、页面结构

```
App.vue（全局导航栏 + router-view）
├── /       → ChatView.vue   基础对话
├── /agent  → AgentView.vue  Agent 订单查询（工具调用步骤）
├── /rag    → RagView.vue    知识库问答（参考来源标签）
└── /graph  → GraphView.vue  智能客服（全功能模式，节点轨迹、意图标签）
```

## 九、设计模式 & 亮点

1. **Composable 分层**：逻辑与视图彻底分离，视图层极薄
2. **手动 SSE + POST**：不依赖 EventSource，支持 POST 请求体
3. **会话记忆管理**：`threadId` 清空时刷新（短期记忆归零），`userId` 持久化（长期记忆保留）
4. **前端 Token 安全**：发送时截断最近 10 条历史，避免 Token 超限
5. **类型先行**：全量 TypeScript + 严格模式，SSE 事件用联合类型区分
